# 0143 · 已提交的模型输出携带续聊所需事实

- 状态：accepted
- 关联：[0099](0099-ledger-commits-use-wal-normal.md)、[0100](0100-message-tool-calls-recover-at-turn-granularity.md)、STA-001、STA-002、ERR-001。

会话与模型调用账可以在宿主故障后保留不同的提交前缀。旧输出的协议重放需要调用账中的模型绑定与提供方字段，一条缺失或未结算的回执就会阻断后续请求。

Models 在签发 `model.facts` 时验证调用已成功结算且属于当前绑定。新版消息随原 `Output` 一次提交版本化的模型绑定与必要的提供方重放字段。工具身份、续接状态与显示事实仍在同一内容块内。调用账独立承担计费、请求去重与审计；新版会话投影直接使用该消息中的重放事实。

旧消息优先使用真实成功回执。回执缺失或只剩 `started` 时，投影根据已保存的消息和配对工具结果继续，把受影响的工具组作为历史内容并结束旧的模型续接。调用账仍反映真实状态，其他结算异常继续报告。未结算的工具按 0100 处理。

写入新格式前，回退版本需要具备该格式的读能力。新增字段随消息持久化；备份及保留继续遵循原消息合同。0099 的宿主故障耐久性保证继续适用。

隔离验收覆盖缺行和 `started`，比较重开前后的原始消息和工具结果，记录真实工具执行次数，并检查新版消息在账本回退后仍按原工具 ID 组装请求。
